# Art Site

This is a Django-based web application for showcasing art.

## Repository Cleanup

Before deploying this application, the following directories should be removed from the repository as they are generated and not meant to be tracked by version control:

- `page/artSite/staticfiles/`
- All `__pycache__` directories throughout the project.

These files and directories are now listed in the `.gitignore` file and will not be tracked in future commits.
